# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, categorise, search and delete notes. Notes are stored in the browser using localStorage, meaning they remain available even after the page is refreshed.

## Features

- Add notes
- Delete notes
- Search notes
- Personal, Work and Study categories
- Local storage persistence
- Note counter
- Input validation
- Responsive layout

## How to Run

1. Clone the repository
2. Open the project folder
3. Open index.html in a browser
